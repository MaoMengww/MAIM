# AIM

**AI-Native Instant Messaging Platform**

AIM 是一个融合即时通讯、AI Bot 与知识库的应用平台，提供 Web 客户端，支持日常聊天、AI 协作和基于文档的知识问答。

## 主要功能

- **即时通讯**：单聊与群聊，文本、图片、文件及语音消息，支持编辑、撤回、引用回复和搜索。
- **社交关系**：好友、分组、备注、黑名单与群组管理。
- **AI Bot**：内置与第三方 Bot，支持会话交互、工具调用、流式输出及执行状态查看。
- **知识库**：文档上传与管理，按需检索和读取资料，支持带来源的知识问答。
- **多端同步**：历史消息、已读状态及离线变化同步。
